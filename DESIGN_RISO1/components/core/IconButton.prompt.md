A square, ink-bordered button holding one Unicode glyph — for chrome actions that need no label.

```jsx
<IconButton glyph="⌕" label="Search frames" />
<IconButton glyph="✕" label="Close" />
```

RISO1 ships no icon font. Use the approved glyph set (⌕ ✕ ★ ↗ → ◠) set in Space Mono; never emoji. The visual box can shrink but the tap target stays 44px.
